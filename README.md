#Bookmarklet_picoctf
- This challenges teaches us about bookmarklet, a bookmark that runs JavaScript code when run.
- It also highlights how we can use the console tab to execute scripts and interact with the website directly.
---




#Steps Taken
- Launched the picoctf game.
- Found a website with a bookmarklet.
- The bookmarklet has a JS code that encrypts and decrypts the flag
- Copied the bookmarklet code.
- Opened developer tools with Ctrl Shift I
- Navigated to the console tab
- Pasted the code on the console
- Pressed Enter, and a notification with the flag appeared.
---





#What we Learn
- A bookmarklet is a JavaScript code that runs once it's clicked.
- This JS code can be run o the console.
- The console can be used to interact with the website directly.
